# 에너지정보처리연구실 홈페이지

국립공주대학교 에너지정보처리연구실(Energy Informatics Laboratory) 홈페이지입니다.
GitHub Pages로 공개되며(https://eil-knu.github.io/), 논문·특허·과제·소식·구성원 목록은 **공개 구글 시트**에서 가져옵니다.

## 내용 고치는 법 (대부분 이것만 하면 됩니다)

**학생들은 실적 원장(구글 시트)과 구글 드라이브만 관리하면 됩니다.**

| 바꾸고 싶은 것 | 하는 곳 |
|---|---|
| 논문, 특허, 연구 과제 | 실적 원장의 `논문` / `특허` / `과제` 탭 |
| 연구실 소식 | 실적 원장의 `소식` 탭 (사진은 구글 드라이브 공유 링크) |
| 구성원(재학생·졸업생) | 실적 원장의 `구성원` 탭 (사진은 구글 드라이브 공유 링크) |
| 소개 문구, 교수 약력, 연구 분야 그림 | GitHub의 `src/*.html` 수정 후 `python scripts/build.py` (교수님) |

원장의 `홈페이지 표시` 열이 `Y`인 행만 사이트에 나옵니다. 원장 → 공개 시트(EIL 홈페이지 데이터)는 수식으로 자동 연결되어 있으니 공개 시트는 고치지 마세요.

시트를 고치면 **방문자 화면에는 새로고침 시 바로** 반영되고, 사이트에 저장된 사본(`data/*.csv`)은
**매시간 자동으로** 갱신됩니다. 급하면 GitHub의 Actions 탭 → `시트 데이터 갱신` → `Run workflow`.

### 사진 넣는 법 (구글 드라이브)

1. 연구실 공유 드라이브의 사진 폴더에 사진을 올립니다 (가로 1200px 이상, JPG 권장).
2. 사진 파일 → 공유 → 일반 액세스를 **"링크가 있는 모든 사용자"** 로 바꾸고 → 링크 복사.
3. 시트의 `사진` 칸에 링크를 붙여 넣습니다. 여러 장이면 `;`로 구분합니다. 첫 사진이 대표 사진입니다.

예전 사진처럼 `asc_1.jpg` 같은 파일 이름을 적으면 사이트의 `assets/img/news/`(구성원은 `people/`)에 있는 사진을 씁니다.

### 시트 탭 형식

첫 줄(열 제목)은 바꾸지 마세요. 열 순서로 읽습니다.

- `논문` K열 `DOI`: `10.1109/...` 형태나 전체 주소(https://…) 모두 됩니다. 값이 있으면 논문 제목이 링크가 됩니다.
- `특허` 링크 (선택): 특허 정보 페이지 주소. 값이 있으면 특허 제목이 링크가 됩니다.
- `논문` IF·JCR 4개 열: `IF(최신)` · `JCR 상위%(최신)` · `IF(출판연도)` · `JCR 상위%(출판연도)`. 비워 두면 표시되지 않으며, 화면에는 최신 값만 나옵니다.
  - 실적 원장에서는 논문 탭 O열(DOI)과 T~W열(IF·JCR), 특허 탭 P열(링크)에 입력합니다. 공개 시트는 이 열들을 자동으로 가져옵니다.
  - 상위%는 숫자만 적습니다 (예: `8.3`). JCR의 JIF Percentile이 91.7이면 상위 8.3%입니다.
  - 최신 값은 매년 6월 JCR 발표 후 한 번 갱신하면 됩니다.
  - 현재 값은 JCR 2025 기준이며, 분야가 여러 개면 순위가 가장 높은 분야(순위÷분야 저널 수)로 계산했습니다.
- `소식`: `ID | 날짜 | 제목 | 사진 | 링크 | 홈페이지 표시`
  - ID는 `NW-009`처럼 이어서 붙입니다. 날짜는 `2026-10-21`이나 `2026.10.21` 모두 됩니다. 최신 날짜가 위에 나옵니다.
- `구성원`: `ID | 상태(재학/졸업) | 과정 | 이름 | 영문 이름 | 연구 분야 | 이메일 | 사진 | 비고 | 홈페이지 표시`
  - 과정: `박사과정`, `석박통합과정`, `석사과정`, `학부연구생`, `박사후연구원` (영문으로 자동 표시)
  - 비고: 졸업생의 현재 소속 등 (Alumni 탭에 표시)
  - 순서는 ID 순서입니다.

### 사진 올리기

GitHub 저장소 → 해당 폴더 → `Add file` → `Upload files`. 가로 1200px 이하 JPG를 권장합니다.
연구 분야 그림은 현재 회색 자리 표시(`[① … 그림 · 4:3]`)로 되어 있으니 `src/index.html`, `src/about.html`에서 `<img>`로 바꾸면 됩니다.

## 폴더 구조

```
index.html …           # 생성된 페이지 (직접 고치지 말고 src/를 고친 뒤 build)
src/                   # 페이지 본문
scripts/build.py       # 공통 머리글·바닥글을 붙여 페이지 생성
scripts/fetch_data.py  # 시트 → data/*.csv
data/                  # 시트 사본 (자동 갱신)
assets/css, js, img    # 스타일, 스크립트, 이미지
.github/workflows/     # 매시간 데이터 갱신
```
