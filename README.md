# 에너지정보처리연구실 홈페이지

국립공주대학교 에너지정보처리연구실(Energy Informatics Laboratory) 홈페이지입니다.
GitHub Pages로 공개되며(https://gu-young.github.io/energyinfo/), 논문·특허·과제·소식·구성원 목록은 **공개 구글 시트**에서 가져옵니다.

## 내용 고치는 법 (대부분 이것만 하면 됩니다)

| 바꾸고 싶은 것 | 하는 곳 |
|---|---|
| 논문, 특허, 연구 과제 | 실적 원장(구글 시트)의 `논문` / `특허` / `과제` 탭 |
| 연구실 소식 | 시트의 `소식` 탭 + 사진은 `assets/img/news/`에 업로드 |
| 구성원(재학생·졸업생) | 시트의 `구성원` 탭 + 사진은 `assets/img/people/`에 업로드 |
| 소개 문구, 교수 약력, 연락처 | `src/*.html` 수정 후 `python scripts/build.py` |
| 메뉴, 바닥글 | `scripts/build.py` 수정 후 실행 |

시트를 고치면 **방문자 화면에는 바로** 반영되고(브라우저가 시트를 확인), 사이트에 저장된 사본(`data/*.csv`)은
**매시간 자동으로** 갱신됩니다. 급하면 GitHub의 Actions 탭 → `시트 데이터 갱신` → `Run workflow`.

### 시트 탭 형식

첫 줄(열 제목)은 바꾸지 마세요. 열 순서로 읽습니다.

- `논문` K열 `DOI`: `10.1109/...` 형태나 전체 주소(https://…) 모두 됩니다. 값이 있으면 논문 제목이 링크가 됩니다.
- `특허` K열 `링크` (선택): 특허 정보 페이지 주소. 값이 있으면 특허 제목이 링크가 됩니다.
  - 예전 사이트의 링크는 `data/links.csv`(ID별)에 옮겨 두었습니다. 시트에 값을 넣으면 시트가 우선하며, 모두 옮긴 뒤에는 이 파일을 지워도 됩니다.
- `논문`: 기존 A~K열(ID … DOI) 뒤에 4개 열을 이어서 둡니다. 비워 두면 표시되지 않습니다.
  - L `IF(최신)` · M `JCR 상위%(최신)` · N `IF(출판연도)` · O `JCR 상위%(출판연도)`
  - 상위%는 숫자만 적습니다 (예: `8.3`). JCR의 JIF Percentile이 91.7이면 상위 8.3%입니다.
  - 최신 값은 매년 6월 JCR 발표 후 한 번 갱신하면 됩니다.
  - 현재 값(JCR 2025 기준, 분야가 여러 개면 순위가 가장 높은 분야)은 `data/jcr.csv`에 들어 있습니다. 시트에 값을 넣으면 시트가 우선합니다.
- `소식`: `ID | 날짜(YYYY-MM-DD) | 제목 | 사진 | 링크`
  - 사진: 파일 이름을 `;`로 구분 (예: `asc_1.jpg; asc_2.jpg`). 첫 사진이 대표 사진입니다. 전체 주소(https://…)도 됩니다.
- `구성원`: `ID | 상태(재학/졸업) | 과정 | 이름 | 영문 이름 | 연구 분야 | 이메일 | 사진 | 비고`
  - 과정: `박사과정`, `석박통합과정`, `석사과정`, `학부연구생`, `박사후연구원` (영문으로 자동 표시)
  - 비고: 졸업생의 현재 소속 등 (Alumni 탭에 표시)
  - 순서는 ID 순서입니다.

### 사진 올리기

GitHub 저장소 → 해당 폴더 → `Add file` → `Upload files`. 가로 1200px 이하 JPG를 권장합니다.
연구 분야 그림은 현재 회색 자리 표시(`[① … 그림 · 4:3]`)로 되어 있으니 `src/index.html`, `src/about.html`에서 `<img>`로 바꾸면 됩니다.

## 폴더 구조

```
index.html …           # 생성된 페이지 (직접 고치지 말고 src/를 고친 뒤 build)
src/                   # 페이지 본문
scripts/build.py       # 공통 머리글·바닥글을 붙여 페이지 생성
scripts/fetch_data.py  # 시트 → data/*.csv
data/                  # 시트 사본 (자동 갱신)
assets/css, js, img    # 스타일, 스크립트, 이미지
.github/workflows/     # 매시간 데이터 갱신
```
